CASO DE ESTUDIO

Control de Acciones
y Supervisiones

Data Quality · Business Intelligence · Automation

Solución orientada al seguimiento integral de acciones levantadas en tiendas, supervisiones y avance operacional, combinando Power BI, Power Apps, Power Automate, SharePoint y Excel Online.

01 / OVERVIEW

De múltiples archivos a un sistema de control.

El objetivo fue construir una solución que permitiera mantener una visión completa del estado de las acciones levantadas en las tiendas y su relación con las supervisiones realizadas.

El proceso permite realizar seguimiento a las acciones abiertas y cerradas, conocer el avance de las acciones durante el período y determinar si las tiendas que presentan acciones han sido posteriormente supervisadas.

De esta manera, la información deja de depender de revisiones manuales para transformarse en un sistema de seguimiento disponible para los equipos involucrados.

BI Modelo de análisis y control
APP Consulta móvil para terreno
AUTO Reportes automáticos diarios
360° Control de acciones y supervisiones
02 / CHALLENGE

El desafío.

Antes de la solución, el seguimiento dependía de procesamiento manual de archivos y generación periódica de reportes.

Era necesario descargar información, preparar tablas dinámicas, revisar los resultados y posteriormente compartir el avance mediante correo electrónico.

Este proceso debía repetirse diariamente para mantener informados a los equipos sobre las acciones pendientes, acciones cerradas, supervisiones y avance del período.

Además, la información necesitaba ser analizada desde diferentes dimensiones para poder identificar rápidamente qué estaba ocurriendo y dónde era necesario realizar seguimiento.

03 / SOLUTION

La solución.

Una solución integrada que conecta fuentes de datos, análisis, aplicaciones y automatización para centralizar el seguimiento operacional.

BUSINESS INTELLIGENCE

Modelo analítico

Se construyó un modelo de Power BI que integra y relaciona las diferentes fuentes de información necesarias para realizar el seguimiento.

El modelo incorpora relaciones, medidas DAX, columnas calculadas y estructuras orientadas al análisis operacional.

Power BI DAX Data Modeling
POWER APPS

Consulta durante la operación

Se desarrolló una aplicación para que el equipo pueda consultar información relacionada con las acciones levantadas en las tiendas.

La aplicación facilita el acceso a la información durante la operación y permite trabajar con los datos asociados al seguimiento de las acciones.

Power Apps SharePoint Power Platform
PROCESS AUTOMATION

Distribución automática

Después de la actualización de Power BI, Power Automate utiliza la información disponible para generar y distribuir diferentes tipos de reportes.

Se generan resúmenes generales, avance del mes, información específica de supervisiones, desglose por auditor y seguimiento de acciones pendientes o atrasadas.

Power Automate Power BI Ooutlook
DATA SOURCES

Fuentes de información

La solución utiliza información almacenada en Excel Online y SharePoint, que posteriormente es integrada dentro de los modelos semánticos utilizados por Power BI.

Esto permite centralizar las fuentes y mantener una estructura preparada para los procesos de análisis y automatización.

Excel SharePoint Power BI
04 / VISUAL EVIDENCE

La solución en funcionamiento.

Algunas de las herramientas desarrolladas para visualizar la información y automatizar el seguimiento operacional.

POWER BI · DASHBOARD

Dashboard de seguimiento.

El dashboard permite centralizar la información de acciones y supervisiones, facilitando el análisis del estado de las acciones, avance del período y principales indicadores de seguimiento.

La información puede analizarse utilizando diferentes dimensiones operacionales para identificar rápidamente situaciones que requieren atención.

POWER AUTOMATE · AUTOMATIZACIÓN

Automatización de reportes.

Power Automate permite ejecutar procesos posteriores a la actualización de la información y distribuir automáticamente los reportes requeridos por los equipos.

De esta forma, la información preparada en Power BI puede transformarse automáticamente en comunicaciones y reportes destinados a los distintos responsables.

05 / DATA FLOW

Flujo de información.

El proceso conecta las fuentes de información con el modelo analítico, la aplicación y los procesos de distribución automática.

El flujo funciona como un ecosistema conectado desde la captura y almacenamiento de información hasta el análisis y distribución de resultados.

Excel Online SharePoint Power BI Data Modeling DAX Refresh Power Automate Power Apps Outlook
06 / CONTROL

Una visión completa del avance.

El modelo permite analizar el estado de las acciones levantadas y determinar cuáles continúan abiertas y cuáles han sido cerradas.

También permite relacionar las acciones con las supervisiones realizadas, identificando si una tienda con acciones pendientes ha sido posteriormente supervisada.

La información puede analizarse por diferentes dimensiones, incluyendo período, auditor, tienda, acción y supervisión.

De esta forma, el sistema proporciona una visión integral del avance y permite identificar rápidamente situaciones que requieren seguimiento.

OPEN Acciones abiertas
CLOSE Acciones cerradas
KPI Indicadores de avance
TEAM Seguimiento por auditor
07 / AUTOMATION

Información lista al comenzar la jornada.

Uno de los principales cambios fue trasladar la preparación diaria de información desde un proceso manual hacia un flujo automatizado.

Durante la noche se actualiza la información utilizada por Power BI. Una vez disponible el nuevo contenido, Power Automate ejecuta los procesos de distribución definidos.

Los equipos reciben automáticamente los resúmenes, avances, indicadores y desgloses necesarios para comenzar la jornada con la información actualizada.

Esto elimina la necesidad de descargar archivos, construir tablas dinámicas y preparar manualmente los correos de seguimiento cada día.

08 / IMPACT

Resultado.

Información disponible

Los equipos pueden acceder a información actualizada sin depender de una preparación manual previa.

Consulta durante la operación

Power Apps permite consultar información relacionada con las acciones directamente durante la operación en terreno.

Automatización diaria

Los reportes y resúmenes se distribuyen automáticamente después del proceso de actualización.

Menos intervención manual

El seguimiento dejó de depender de descargar archivos, construir tablas dinámicas y preparar manualmente los reportes diarios.
