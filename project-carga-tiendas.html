Bloques · Tiendas · Automatización

Automatización de un proceso de generación de solicitudes de carga de tiendas mediante Microsoft Forms, Power Automate, Power BI y Excel.

01 / OVERVIEW

De una solicitud manual a un proceso automatizado.

El sistema fue desarrollado para automatizar la preparación de solicitudes de carga de tiendas agrupadas dentro de un mismo bloque.

Antes de la automatización, la preparación de una solicitud requería buscar manualmente las tiendas asociadas a un bloque, identificar sus respectivos Response ID y recopilar información adicional desde diferentes fuentes.

Posteriormente, toda esta información debía ser organizada manualmente dentro de un template para generar el archivo que finalmente sería utilizado para realizar la carga en la plataforma.

La solución automatiza gran parte de este proceso, utilizando el código del bloque como punto de partida para recuperar y consolidar la información necesaria.

BI Consulta del modelo semántico

02 / CHALLENGE

El proceso anterior.

La preparación de cada solicitud dependía de múltiples búsquedas y tareas manuales.

La persona encargada debía identificar todas las tiendas pertenecientes a un determinado bloque y buscar el Response ID correspondiente a cada una.

Además, debía consultar información adicional de la colecta, como estados y otros campos necesarios para completar correctamente el archivo.

Finalmente, todos estos datos debían ser agrupados manualmente en un template antes de poder realizar la carga.

03 / SOLUTION

La solución automatizada.

INPUT

Solicitud

El proceso comienza cuando una persona completa un Microsoft Form indicando el código del bloque, el auditor que será asignado y la fecha correspondiente.

Microsoft Forms
AUTOMATION

Activación del flujo

El envío del formulario dispara automáticamente un flujo de Power Automate mediante el evento "When a new response is submitted".

Power Automate
DATA

Consulta de información

El flujo obtiene la información de la solicitud y consulta el modelo semántico de Power BI para recuperar los registros asociados al código del bloque.

Power BI Semantic Model
DATA PROCESSING

Cruce y procesamiento

La información recuperada es procesada mediante filtros, variables, composiciones y ciclos para construir la información necesaria para cada tienda.

Filter Array Apply to Each Variables Compose
OUTPUT

Generación del archivo

Los datos obtenidos se incorporan automáticamente en un template Excel online con todos los campos requeridos para realizar la carga.

Excel Microsoft 365
DELIVERY

Solicitud automática

Una vez generado el archivo, Power Automate prepara y envía automáticamente un correo con la información de la solicitud, el archivo y un resumen en formato HTML.

Outlook Power Automate
04 / AUTOMATION FLOW

Flujo de información.

El proceso completo conecta la captura de la solicitud, consulta de datos, transformación y generación del resultado.

Microsoft Forms Power Automate Obtener respuesta Compose Power BI Query Dataset Filter Array Apply to Each Variables Excel Online Outlook
05 / DATA INTEGRATION

Integración con Power BI.

El modelo semántico de Power BI actúa como una fuente centralizada para recuperar la información necesaria para construir la solicitud.

A partir del código del bloque ingresado en el formulario, el proceso identifica todas las líneas asociadas y recupera los datos necesarios para construir el archivo.

Entre la información utilizada se encuentran los Response ID de las tiendas, Response Status, Response Name, estado de carga, código del auditor y fechas de inicio y término.

BLOCK ID Identificador utilizado para buscar las tiendas
RESPONSE Identificación de cada registro asociado
STATUS Estado de la información y carga
DATE Fechas utilizadas en la solicitud
06 / OUTPUT

Resultado del proceso.

Template preparado

El archivo Excel es completado automáticamente con la información necesaria y queda preparado para ser utilizado directamente en el proceso de carga.

Correo automático

El solicitante recibe una comunicación automática con los datos de la solicitud y el archivo generado.

Resumen HTML

El correo incorpora además una tabla HTML con un resumen de la información generada, facilitando su revisión y utilización.

Intervención mínima

La intervención humana queda prácticamente reducida a completar la solicitud inicial y posteriormente realizar la carga del archivo generado.

07 / IMPACT

Impacto de la automatización.

El principal resultado fue transformar un proceso manual de recopilación y preparación de información en un flujo automatizado.

Antes, cada solicitud requería aproximadamente 15 minutos de trabajo manual entre búsquedas, cruces de información y preparación del template.

Con la automatización, el proceso genera automáticamente la información necesaria y prepara el archivo para la carga.

En la operación diaria, esto representa un ahorro aproximado de dos horas de trabajo, además de reducir la posibilidad de errores derivados de la manipulación manual de información.
